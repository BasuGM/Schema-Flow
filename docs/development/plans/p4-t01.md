## A — `src/analysis/health.ts` (pure TS)

```ts
export type HealthCheckId = "missing-pk" | "unindexed-fk" | "orphan-table" | "naming";
export interface HealthFinding {
  check: HealthCheckId;
  severity: "warning" | "info";
  message: string;
  tableId: TableId;
  columnIds?: ColumnId[];
}
export function analyzeSchema(schema: Schema): HealthFinding[]  // sorted: severity, check, table order
export function countFindings(f): Record<HealthCheckId, number>
export function findingsToText(f): string                          // for Copy, like issuesToText
```

Declared tables only (`origin: "implicit"` skipped). Table names in messages are
schema-qualified (`billing.invoices`) when the schema has more than one `schemaName`, else bare
(amendment 4).

| Check | Severity | Rule |
| --- | --- | --- |
| missing-pk | warning | `table.primaryKey` absent or empty |
| unindexed-fk | info | FK `from.columnIds` is covered when, as a **set**, it equals the leading k columns (k = FK size) of any index, unique constraint or PK of the child table (index (a,b) covers FK (b,a) and FK (a)). Findings deduped per (table, column set). Skipped when `source.dialect === "mysql"`. No partial/expression index handling (amendment 1) |
| orphan-table | info | table in no relationship (either end). Skipped when the schema has 0 relationships |
| naming | info | styles: snake_case, camelCase, PascalCase, ALL_CAPS, other (single lowercase word counts as snake and camel). Majority style per kind (tables, columns) across the schema; skip a kind with < 10 names or no ≥ 60 % majority. **At most one finding per table**: table name off-style and/or its off-style columns, together (amendment 5) |

Fixtures (amendment 6): `tests/fixtures/sql/health.postgres.sql` (small; triggers all four checks)
and `tests/fixtures/sql/health.mysql.sql` twin proving the unindexed-fk skip.

Tests `src/analysis/health.test.ts`: each rule positive + negative; set-coverage cases ((a,b) covers
(b,a) and (a); (a,b) does not cover (b)); dedupe; MySQL skip; implicit skip; zero-relationship
skip; naming ALL_CAPS / < 10 names / no majority / one finding per table; multi-schema qualified
names; deterministic order; both health fixtures parsed end to end. A counts test over ecommerce
sample, `tests/fixtures/synthetic/saas-300.postgres.sql` and
`tests/fixtures/real/mysqldump-180.mysql.sql` prints the numbers recorded in the handoff.
