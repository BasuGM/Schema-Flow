## Workstream B — text tabs

`src/components/export/export-text-panel.tsx` (one component, parameterised by tab):

- **Options** (existing `OptionGroup` radios):
  - SQL dialect PostgreSQL / MySQL / SQLite (`export-dialect-*`). The default is `schema.source.dialect` when present, otherwise PostgreSQL.
  - Mermaid columns All / Keys (`export-mermaid-*`).
  - Prisma and JSON have no options.
- **Generation:** a dynamic `import("@/generators/text/generate-text")` (lazy, like ADR-014 parsers), run after `afterNextPaint()` with a "Generating…" busy state. Results are memoised per `(fingerprint, target)` in component state, so switching tabs back is instant. A thrown error (should not happen) becomes an inline `role="alert"`.
- **Preview:** a read-only `<pre>` in a scroll box (`export-preview`, `tabIndex=0`, `aria-label="<Target> preview"`, mono 12, `max-h-[50dvh]`). It is capped at the first 2,000 lines / 200 KB. When the output is longer, a note says "Preview shows the first 2,000 of N lines. Copy and Download include everything." (`export-preview-truncated`). This keeps GitLab responsive.
- **Size line** (`export-text-size`): "N lines · X KB".
- **Warnings** (`export-warnings`): the count plus a collapsible `<details>` list. "No warnings" when empty.
- **Copy** (`export-copy`): `copyText` from [src/lib/copy-text.ts](src/lib/copy-text.ts) copies the full text. A polite live region announces "Copied" or "Copy failed — use Download" (`export-copy-status`).
- **Download** (`export-download-text`): `downloadBlob` ([src/lib/download.ts](src/lib/download.ts)) with `targetFile(target).mime` and `exportFileName(schema.name, extension)` from [src/generators/raster-size.ts](src/generators/raster-size.ts). File names get a suffix to keep them apart: `<slug>.postgresql.sql` / `.mysql.sql` / `.sqlite.sql`, `schema.prisma` → `<slug>.prisma`, `<slug>.mmd`, `<slug>.json`. Downloading doesn't close the dialog, so the user can export several formats.

### Amendments (user, plan review)

1. **Cache key.** Not the fingerprint, which hashes only table IDs and column names. Add a `revision` counter to `schema-store` that increases on every `setSchema`/import. Memo key = `revision` + target + options (dialect, mermaid columns). Test: import A, open SQL, then import A′ with a changed default and reopen. The preview shows the new default.
2. **Race guard.** Each generation carries a request id. A result is applied only if its (target, options, revision) still matches what is visible. Test: switch SQL → JSON while SQL is generating. The JSON tab never shows SQL text.
3. **Safari/iOS gesture.** Copy and Download stay disabled until the text is ready. Their click handlers are synchronous:
   - Copy: `copyText` is split so `navigator.clipboard.writeText(text)` is called with no prior await. The `execCommand` fallback is attempted synchronously in the same handler if `clipboard` is unavailable, and a rejected promise reports "Copy failed — use Download".
   - Download: the blob is built from the ready text in the handler, with no awaits.
4. **e2e byte-for-byte.** Each downloaded file must equal the CLI output for the same sample source. Add `scripts/headless/generate.ts --sample` (or point it at the e2e sample's source file) so both start from the same schema. If the header or schema name differs, make the inputs equal; don't loosen the test.
5. **Toolbar without tables.** `aria-disabled` (still focusable, tooltip readable) via the existing `unavailable` prop. Clicking or pressing Enter does nothing. Test included.
6. **Phone tabs.** At 344 px, arrow keys scroll the focused tab into view (`scrollIntoView({ block: "nearest", inline: "nearest" })` on focus). Focus rings are not clipped (padding on the scroll container). e2e at 390: arrow to Image; it is visible and focused.
7. **QA-030 inspector check** in the handoff: GitLab `users.email` default shows `''`. **Deviation:** not `''::character varying`. The parser intentionally removes casts from literal defaults (existing behaviour: `'member'::account_role` → `'member'`, tested in `parse-default.test.ts`). The defect was the truncated `''::`, and that is what is checked. The handoff states this so Cowork doesn't flag it.
8. **Handoff** opens with one short user-facing paragraph on what the app now shows, then the steps.

Also finish the round-18 bookkeeping that plan mode blocked: append the QA_LOG round-18 entry and update the ROADMAP Now block and the P3-T04 status line.
