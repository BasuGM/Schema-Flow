**Deviations from the plan:**

- The CLI needs `--experimental-transform-types` (documented in its header), not plain type
  stripping: the SQL parser uses TypeScript parameter properties. No dependency added.
- The CLI found a real gap in the first version: MySQL `SET(…)`, `YEAR` and `… UNSIGNED` types
  (Sakila) were copied through and broke SQLite. Fixed in `be538b6` (type map + a SQLite execution
  test over Sakila, mysqldump-180 and shop.mysql).
- Round-trip comparison leaves out comments (PostgreSQL `COMMENT ON` and table comments are not
  read back by the SQL parser); `CANONICAL_EXCLUDED` lists every excluded field with its reason.
