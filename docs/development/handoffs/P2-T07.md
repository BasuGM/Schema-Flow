**Known limitations:**

- Search covers table and column names only. Enums, indexes, constraints and comments are not
  included (P2-T08 can extend the index).
- There is no collapse-mode UI yet (P3-T02). The "hidden row is still shown" behaviour is covered
  by an automated test only.
- After choosing a result, focus doesn't move onto the table node; this is deliberate, because
  focusing a node can auto-pan it away from the centred row.
