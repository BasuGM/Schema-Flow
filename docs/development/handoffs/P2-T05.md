**Context.** SchemaFlow is a browser-only database schema explorer that turns a schema into an
interactive entity-relationship diagram. The SQL and Prisma parsers (P2-T01…T04, Verified) are now
reachable from the UI:

- the toolbar's **Import** button opens a dialog;
- you paste text or choose or drop a file;
- the dialog previews counts and issues, and **Import** replaces the diagram.

Everything runs in the browser; SQL is tokenized, never executed. The parsers load lazily in their
own chunk (ADR-014).

**How to drive it headlessly:**

- Upload with `setInputFiles('[data-testid=import-file-input]', …)`.
- Drop by dispatching `dragover` and `drop` on `[data-testid=import-dropzone]` with a
  `DataTransfer` containing the file.
- Paste by setting the textarea's `value` and dispatching an `input` event. The textarea is
  uncontrolled and commits 300 ms after the last input.
