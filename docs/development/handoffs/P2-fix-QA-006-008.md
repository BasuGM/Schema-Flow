**What changed**

- **QA-006 (labels clipped):** a hovered or clicked edge label is now measured and shifted
  horizontally to stay at least 8 px inside the visible canvas pane (`labelOverflowShift` in
  `src/graph/edge-path.ts`, applied in `src/components/canvas/relationship-edge.tsx`).
  - This replaces a fitView-based fix, for two reasons. Labels keep a constant ~11 px on-screen
    size since QA-005, so a long label is about 400 screen px wide at every zoom, and no fitView
    padding can contain that without shrinking the diagram. A fitView fix would also not help
    after a pan or zoom.
  - The label shifts only when it would overflow. Otherwise it stays 12 px beside its FK row, as
    before, or 52 px for the self-loop.
- **QA-007 (byte-order mark):** the tokenizer skips a leading U+FEFF. It is skipped, not removed,
  so token offsets still index the original text and line numbers are unchanged.
- **QA-008 (typeless columns):** a bare column name before `,`, `)` or the end of the input is a
  column with an empty type. Each typeless column gets one warning with its line, in both
  `CREATE TABLE` and `ALTER TABLE … ADD COLUMN`. The warning reads:
  `Column "t.name" has no type; its type is shown as empty.`
