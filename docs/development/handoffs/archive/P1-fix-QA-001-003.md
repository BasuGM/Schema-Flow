an interactive entity-relationship diagram (table list · canvas · inspector). Your Phase 1 report
passed almost everything and found three minor defects. Commit `c879f58` fixes them:

- **QA-001** (an edge ran behind `addresses`): long edges now follow routes computed by the
  auto-layout, which go around intermediate tables. A route is used only while both end tables
  are where the layout put them; after you drag an end table, that edge reverts to a direct step
  line until you click "Layout".

  (`user_id → users.id`), sit just outside the FK column row, and draw above tables. The hover
  tooltip still carries the full text with the constraint name.
- **QA-003** (Escape didn't work from the table list): Escape now clears the selection from
  anywhere in the workspace, except inside the filter text box and while a menu is open.
