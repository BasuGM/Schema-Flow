**Context.** The inspector now has three tabs: **Columns · Keys · Relations** (ADR-017).

- **Columns:** type, default, FK target links, comments and enum values.
- **Keys:** primary key, unique constraints, indexes and checks.
- **Relations:** "References" and "Referenced by". Each related table is a link, and "Back"
  returns you.

Two kinds of navigation behave differently:

- Explicit jumps center the canvas: search, FK and key links, and Relations.
- Clicking a column row in the inspector only pans the canvas when that row is off-screen.

On phones, the inspector opens as an overlay sheet.
