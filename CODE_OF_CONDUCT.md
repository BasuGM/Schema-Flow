# Code of Conduct

SchemaFlow follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Read it there; it applies to issues, pull requests, discussions and any other space tied to this
repository.

In short: be respectful, assume good faith, give and take feedback kindly, and don't harass anyone.

## Reporting

To report behaviour that breaks this code, open an issue on
[GitHub](https://github.com/BasuGM/Schema-Flow/issues) or contact the maintainer,
[@BasuGM](https://github.com/BasuGM), through GitHub. There is no email address for this project.

The maintainer will read reports and act on them as the Covenant describes. SchemaFlow is a closed
portfolio project run by one person, so replies may be slow.
